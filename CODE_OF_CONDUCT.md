# Code of conduct

Be kind, be precise, and assume good faith. Criticise code and claims, never people.
Harassment, insults and personal attacks are not accepted in issues, pull requests or
any other project space.

To report a problem, open a
[private security advisory](https://github.com/myfjin/forge-gate/security/advisories/new)
(it reaches only the maintainers) or, if it can be public, an
[issue](https://github.com/myfjin/forge-gate/issues). The maintainers may edit or remove
contributions, and block contributors, that break these rules.
